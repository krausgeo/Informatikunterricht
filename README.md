# Java — Objektorientierte Programmierung (OOP) — Materialien

Dieses Repository enthält interaktive Jupyter-Notebooks zur Einführung in die objektorientierte Programmierung mit Java.
Zielgruppe: Sekundarstufe II — Einstiegsniveau.

Dateien:
- `OOP_Einfuehrung_Java_Offline.ipynb` — Offline-Notebook für lokalen Gebrauch mit IJava-Kernel.
- `OOP_Einfuehrung_Java_Online_Colab.ipynb` — Colab-kompatibles Notebook (installiert Java & Graphviz automatisch).
- `environment.yml`, `postBuild` — Binder-Konfiguration, damit du das Repo auf mybinder.org starten kannst.

## Nutzung
Für die Offline-Version: installiere IJava (siehe Anleitung im Notebook).
Für die Colab-Version: einfach öffnen in Colab (siehe Link). Die erste Zelle installiert Java & Graphviz.
